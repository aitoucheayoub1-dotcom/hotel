# Gestion Hôtel (hotel)

Application web de gestion et réservation d'hôtel développée avec PHP, MySQL (PDO), HTML et CSS.

## Exécution locale
1. Placer le dossier `hotel` dans `C:\xampp\htdocs\hotel`.
2. Démarrer **Apache** et **MySQL** depuis XAMPP.
3. Ouvrir `http://localhost/hotel` dans le navigateur.
